1. OVERVIEW & WHAT HAPPENED MOVING FROM WINDOWS TO MAC
--------------------------------------------------------------------------------
When moving a machine learning computer vision project from Windows to macOS:

1. Old Windows Virtual Environment ('rats'):
   - Virtual environments contain hardcoded binary executables (.exe, .ps1) and
     OS-specific symlinks. They cannot be transferred across operating systems.
   - Fix: The old 'rats' folder is replaced with a fresh native macOS venv.

2. Windows Wheel Files ('*.win_amd64.whl'):
   - Windows binary wheels (e.g., dlib-*-win_amd64.whl) cannot be installed on Mac.
   - Fix: On Apple Silicon Mac (ARM64), dlib must be compiled natively using CMake.

3. Dlib & CMake Compilation on Apple Silicon:
   - Compiling dlib on modern macOS requires CMake and OpenBLAS / LibPNG.
   - We installed Homebrew build dependencies and compiled dlib natively (v20.0.1).

4. Python Version Selection:
   - Python 3.11 was selected because packages like dlib, mediapipe, and
     face-recognition have stable Apple Silicon support on 3.11.

5. Mac Built-in FaceTime Camera Index:
   - On Windows, cameras are often index 0 or 1.
   - On macOS, the built-in FaceTime HD camera is ALWAYS index 0:
     cap = cv2.VideoCapture(0)

6. macOS Port 5000 Conflict (AirPlay Receiver):
   - macOS Monterey / Ventura / Sonoma / Sequoia use port 5000 for AirPlay Receiver.
   - You can either turn off AirPlay Receiver in System Settings or run scripts on
     dedicated ports (e.g. 5001, 5003).

3. PYTHON LIBRARIES & PURPOSE
--------------------------------------------------------------------------------
The project uses the following key libraries:

1. Flask (3.1.3):
   Web framework serving the web interface, live video streaming, authentication,
   and attendance reporting routes.

2. OpenCV (opencv-python 5.0.0):
   Captures live video frames from your webcam, converts color spaces (BGR to RGB/GRAY),
   draws bounding boxes and landmarks, and encodes frames to JPEG for browser streaming.

3. Ultralytics YOLO (8.4.118):
   Deep learning object and face detector (YOLOv5 and YOLOv8 models) accelerated by
   Apple Silicon GPU Metal Performance Shaders (MPS).

4. Dlib (20.0.1):
   C++ machine learning library used for 68-point facial landmark predictor
   (shape_predictor_68_face_landmarks.dat) to compute Eye Aspect Ratio (EAR) for blink detection.

5. face-recognition (1.3.0) & face-recognition-models:
   Extracts 128-dimensional face embedding vectors from facial images.

6. scikit-learn (1.9.0):
   Uses KDTree (k-dimensional tree) for instant nearest-neighbor matching of detected
   faces against enrolled faces in known_faces.csv.

7. SciPy (1.17.1):
   Computes Euclidean distances between eye coordinates for blink calculation.

8. MediaPipe (mediapipe 0.10.9 / 0.10.14):
   Google's real-time hand tracking framework used for hand gesture detection.

9. setuptools (<80):
   Ensures backward-compatible resource loading for face_recognition_models.

7. MAC TROUBLESHOOTING & TIPS
--------------------------------------------------------------------------------
Q1: The camera screen is black or doesn't open.
A1: macOS requires camera permissions.
    Go to: Apple Menu > System Settings > Privacy & Security > Camera.
    Make sure your Terminal (or VS Code / IDE) toggle is turned ON.

Q2: Port 5000 'Address already in use' error.
A2: macOS uses port 5000 for AirPlay Receiver.
    Go to: Apple Menu > System Settings > General > AirDrop & AirPlay.
    Turn 'AirPlay Receiver' to OFF, or run Yolov8Eye.py on port 5003.

Q3: How to add a new person's face?
A3: 1. Place their clear photo inside the 'photos/' folder (e.g. photos/john.jpg).
    2. Add an entry to 'known_faces.csv':
       photos/john.jpg,John Doe,1001
    3. Restart your Python script. The KDTree will automatically load the new face!
