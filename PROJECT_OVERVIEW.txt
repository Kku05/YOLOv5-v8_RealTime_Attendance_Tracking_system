==============================================================================
RATS: REAL-TIME ATTENDANCE TRACKING SYSTEM - PROJECT OVERVIEW
==============================================================================

1. EXECUTIVE SUMMARY
------------------------------------------------------------------------------
RATS is an automated computer vision platform designed for smart educational 
institutions. It replaces manual roll calls and proxy attendance by:
- Recognizing registered students in real-time from high-definition video streams.
- Performing active anti-spoofing liveness verification (eye blinks or hand gestures).
- Managing institutional classes, teacher class assignments, and substitute sessions.
- Securing accounts with cryptographic password hashes and role-based access control.

2. CORE TECHNOLOGIES
------------------------------------------------------------------------------
- Runtime: Python 3.11
- Web Framework: Flask (with Werkzeug Security & Jinja2)
- Object & Person Detection: Ultralytics YOLOv8 & YOLOv5
- Facial Landmarks: Dlib 68-point Shape Predictor
- Hand Gesture Tracking: Google MediaPipe (21 3D Landmarks)
- Face Recognition & Embeddings: face_recognition (dlib ResNet 128-D vectors)
- Nearest Neighbor Indexing: Scikit-learn KDTree (O(log N) search)

3. FILE & DIRECTORY STRUCTURE
------------------------------------------------------------------------------
- app.py                     : Unified Enterprise Application (Port 5001)
- run_mac.sh                 : Interactive macOS Terminal Launcher
- shape_predictor_68_...dat  : Dlib 68-point facial landmark predictor (~99MB)
- yolov8/                    : YOLOv8 model weights (yolov8n.pt, yolov8l.pt)
- yolov5/                    : YOLOv5 model weights (yolov5s.pt, yolov5su.pt)
- classes.csv                : Institutional class catalog
- users.csv                  : User credentials (salted scrypt hashes & roles)
- known_faces.csv            : Registered student database (image, name, id, class, email)
- photos/                    : Gallery of enrolled student portrait images
- attendance/                : Saved attendance CSV logs (by teacher/class/date)
- templates/                 : Web interface templates (login, home, register, take, see)
- static/                    : Static UI assets
- legacy/                    : Standalone legacy Python scripts
