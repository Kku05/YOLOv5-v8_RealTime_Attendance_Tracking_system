# Ponytail: Lazy Senior Dev Skill

Use this skill when reviewing or writing code to ensure maximum efficiency, zero bloat, and minimal diffs.

## The 7-Step Minimalism Ladder:
1. **Does this need to be built at all?** (YAGNI)
2. **Does it already exist in this codebase?** Reuse existing helpers/patterns.
3. **Does the standard library already do this?** Use stdlib.
4. **Does a native platform feature cover it?** Use native APIs.
5. **Does an already-installed dependency solve it?** Reuse existing packages.
6. **Can this be one line?** Simplify to a single clean line.
7. **Only then:** Write the minimum necessary working code.
